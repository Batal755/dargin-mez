# Мез — даргинский язык

Даргинский язык с нуля: слова с картинками, разговорные фразы и сценки, по пять минут в день.
**Открыть:** https://batal755.github.io/dargin-mez/

Сделана по образцу аварского приложения «МацӀ» (avar-maci.vercel.app), код написан заново.

## Что внутри

- 15 разделов, 69 уроков: слова с картинками, фразы, короткие истории-диалоги.
- 149 слов, 52 фразы, 6 диалогов, 10 пословиц, алфавит из 46 букв, 9 подсказок по грамматике.
- Опыт (XP), серия дней, сердца, задания дня, звания (от «Мукьара» — ягнёнок до «Дубура» — гора).
- Повторение слабых слов, словарь с поиском.
- «Проверка для носителя» (Профиль → Открыть проверку): отметить «верно / ошибка», вписать правильный вариант,
  сохранить файл с отметками. Исправления сразу видны в уроках на этом устройстве.
- Работает без интернета после первого открытия (PWA), можно добавить на главный экран телефона.

## Откуда слова

- «Русско-даргинский словарь» М.-Ш. Исаева и «Русско-даргинский разговорник» У. У. Гасановой
  (по публикации на https://www.mekegi.com/dictionary/).
- Литературная норма (акушинская основа). Курс **ещё не проверял носитель языка**: фразы-примеры
  «Иш … саби» («Это …») собраны по правилу и тоже требуют проверки.

## Как править курс

Все слова, фразы, разделы и диалоги — в `js/data.js`. Палочку там пишут латинской `I`, приложение само заменяет её на `Ӏ`.
После правок поменяйте версию кэша `CACHE` в `sw.js` (например, `mez-v2`), иначе телефоны покажут старую версию.

## Запуск на компьютере

```bash
python3 -m http.server 5178 --directory ~/Projects/Dargin-Mez
```

Затем откройте http://localhost:5178.
